## 홈 상호작용 원칙

대문에서는 context 요구사항에 따라 다음 두 버튼만 제공한다.

- 서비스 시작
- 가이드 보기

운영정보와 서비스 구조는 정적 정보로 보여주며 홈에서 별도 제3의 행동 버튼을 두지 않는다.

## 정보구조

```text
서비스 홈
→ 평가 유형 선택
   → 정형 데이터 입력 → 참조 데이터 → 평가 결과
   → 비정형 데이터 확장 로드맵
→ 운영·검증 정보(진입 후 사이드바)
```

## 비정형 확장성

현재 금액 엔진은 정형 데이터에 한정한다. 비정형은 다음 모듈을 독립 개발할 수 있도록 공통 포털만 선반영했다.

- 의료영상
- 임상텍스트
- 음성·대화
- 파형·시계열

각 모듈은 획득비, 주석비, 품질, 저장, 개인정보 위험, 희소성, AI 활용성의 독립 참조표를 가져야 한다.
