# Step 2 수가 미매핑 변수 처리 원칙

## 1. 직접 수가 매핑을 제한하는 변수

다음 변수는 헬스 데이터로 중요하지만 독립된 의료행위 급여단가가 없거나 진찰료·검진패키지·장비비에 포함될 수 있으므로 유사한 Step 2 항목에 임의 매핑하지 않는다.

- 키, 체중, BMI, 허리둘레
- 단회 혈압, 맥박, 호흡수, 체온
- 악력과 단순 신체기능 측정
- BIA 체성분
- 소비자 웨어러블 걸음수·활동량·수면
- 가정혈압·자가혈당
- 흡연·음주·신체활동·삶의 질 설문

## 2. 처리방법

- 인구학·설문·식이 변수: Supplement Table의 5,610원 대분류 배분식을 사용
- 검사·검사실 변수인데 카탈로그에 없는 경우: `manual_unit_price_krw` 사용
- 평가에서 제외할 변수: `Weight & Not Used & Etc`로 분류
- 직접입력 수가의 근거는 별도 내부 문서에 기록

## 3. 직접입력 수가 근거 예시

- 수행인력 직종과 시간
- 장비 감가상각과 유지비
- 소모품
- 데이터 전송·저장·클라우드 비용
- 품질검수와 라벨링 비용
- 환자 또는 조사대상자 보상

유사한 의료행위를 편의상 연결하면 데이터 생성비용이 과대·과소평가될 수 있으므로 금지한다.
