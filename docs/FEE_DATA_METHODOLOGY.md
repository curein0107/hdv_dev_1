# Step 2 의료행위 수가 데이터 적용 방법론

문서 버전: 2025.3  
적용 파일: `data/step2_medical_unit_fee.csv`

## 1. 목적

Step 2 파일은 디지털 헬스, 국가 건강조사, EHR/CDW, 마이헬스웨이에서 변수로 재사용되는 검사·영상·생체신호·병리 데이터를 대표 의료행위 단가와 연결하기 위한 운영용 참조표다.

건강보험 전체 행위의 전수본이 아니며, 현재 프로젝트에서 제공된 103개 대표행위를 사용한다.

## 2. 최종 스키마

```text
fee_name_ko,fee_name_en,procedure_group,data_variable,fee
```

| 필드 | 역할 |
|---|---|
| `fee_name_ko` | 화면 선택과 정확조회에 사용하는 의료행위 한글명 |
| `fee_name_en` | 영문 검색·표시 |
| `procedure_group` | 의료행위군 |
| `data_variable` | 생성 데이터 변수와 검색 토큰 |
| `fee` | Step 2 공통 기본단가(KRW) |

## 3. 컬럼명 변경

기존 검토과정에서 사용됐던 `hospital_base_before_addon_krw`는 제거한다. 최종 공통 단가 컬럼명은 `fee`다.

기관별 단가 열도 Step 2에서 제거한다. 기관 규모 효과는 Step 3에서 15%, 20%, 25%, 30%를 한 번 적용한다. 따라서 Step 2 기관별 가격과 Step 3 가중치를 동시에 적용하던 중복 가능성을 구조적으로 제거했다.

## 4. 조회 원칙

1. 사용자가 직접입력 수가를 입력하면 이를 우선한다.
2. 그렇지 않으면 `fee_name_ko` 선택값을 정확 일치로 조회한다.
3. 선택값이 없으면 변수명·설명이 `fee_name_ko`, `fee_name_en`, `data_variable` 토큰과 정확 일치할 때만 자동 매핑한다.
4. 퍼지 매칭은 후보추천에만 사용하고 사용자의 확인 없이 금액 계산에 적용하지 않는다.
5. 미매핑 검사 변수는 오류로 차단한다.

## 5. 카탈로그 프로파일

- 의료행위: 103건
- 의료행위군: 19개
- 최소 fee: 850원
- 중앙 fee: 10,740원
- 최대 fee: 488,290원
- 중복 한글 의료행위명: 0건
- 0 이하 fee: 0건

## 6. 변경관리

Step 2가 갱신되면 다음을 수행한다.

1. 5개 열 스키마 확인
2. 중복·결측·음수 검사
3. 103개 대표행위 범위 변경 여부 기록
4. `reference_manifest.json` SHA-256 갱신
5. 회귀시험 수행
6. 앱·프로파일 버전 증가
7. 변경이력 공개
